# システム概要

## 1. サービス概要

Japan Fitness Contest は、日本国内の筋トレ・フィットネス競技、および日本人選手が出場する海外大会の情報を一元化する非公式情報サイトです。大会日程や開催情報を、一覧・カレンダー・詳細ページから確認できるようにします。

対象団体として元資料には ZeniX、JBBF、IFBB が、既存READMEには FWJ、JBBF、IFBB が記載されています。正式な対象団体は未決定事項です。

## 2. 解決する課題

- 大会情報が団体ごとのWebサイトやSNSに分散している
- 利用者が複数の情報源を巡回しなければ日程を把握できない
- 運営者が大会情報を継続的に登録・修正・公開できる管理手段が必要
- 検索エンジンから大会情報へ到達できる、整理された公開ページが必要

## 3. 目的

1. 大会情報を一元化する
2. 大会日程を月間カレンダーで確認できるようにする
3. 管理画面から大会情報を登録・編集・削除できるようにする
4. 公開・非公開を制御し、安全に情報を準備・公開できるようにする
5. 無料枠を中心に公開・運用を開始する
6. 将来的な広告、アフィリエイト、スポンサー掲載につなげる

## 4. 想定利用者

| 利用者 | 主な目的 | 権限 |
| --- | --- | --- |
| 一般閲覧者 | 大会を探す、日程・会場・公式情報を確認する | 公開済み大会の閲覧 |
| 選手・参加予定者 | 出場候補大会の開催日や公式案内を確認する | 公開済み大会の閲覧 |
| 観戦者 | 直近の大会や開催場所を確認する | 公開済み大会の閲覧 |
| 管理者 | 大会情報を登録・更新・削除・公開する | 認証後に全大会を管理 |

Phase 1 の管理者は単一ロールを想定します。編集者・承認者などの細かな権限分離は対象外です。

## 5. Phase 1 スコープ

### 対象

- トップページ
- 大会カレンダー
- 大会詳細ページ
- 管理者ログイン、管理ダッシュボード
- 大会の一覧・登録・編集・削除
- 大会の公開・非公開切替
- スマートフォン対応
- PostgreSQLへの永続化
- 基本SEO、Googleインデックス対応
- Vercelへの公開

### 対象外

- 大会結果管理、選手管理、選手ページ
- コメント、外部サイトからの自動データ取得
- SNS連携、CSVインポート
- 新着情報のメール配信、メールマガジン購読
- ブログ、広告、アフィリエイト
- 一般利用者向けアカウント、多言語対応

## 6. 成功の定義

- 一般閲覧者が公開済み大会をトップ、カレンダー、詳細から確認できる
- 管理者がログインし、大会情報のCRUDと公開状態の変更を行える
- 非公開大会が公開画面および公開APIから取得できない
- 主要画面がスマートフォンとPCで利用できる
- SEO用メタデータ、サイトマップ、robots、構造化データが提供される
- 本番環境がVercelとPostgreSQLで稼働する

## 7. 前提・制約

- 本サービスは各競技団体・大会運営とは関係のない非公式サイトとする
- 最新かつ正確な情報の確認先として公式URLを案内する
- Phase 1 は低コスト運用を優先し、Vercel、NeonまたはSupabase、GitHubの無料枠を利用する
- 技術基盤は Next.js App Router、TypeScript、Hono、Drizzle ORM、PostgreSQL、Tailwind CSS とする
